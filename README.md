## ✨ Key Features

- **Modern Glassmorphism UI:** A sleek, translucent design system with noise overlays and dynamic background gradients.
- **Advanced Animations:** Complex scroll-triggered and interactive animations built with `framer-motion`, including a custom 5-card fan layout for technical skills.
- **SEO & Metadata Optimized:** Fully configured OpenGraph and Twitter cards, dynamic routing, and semantic HTML structure.
- **Live Analytics:** Integrated `@vercel/analytics` for real-time traffic monitoring and performance insights.
- **Responsive Architecture:** Fluid design that scales perfectly from mobile devices to ultrawide desktop monitors.
- **Verified Credentials:** Interactive timelines with direct routing to official Coursera and Google certification verification URLs.

## 🛠️ Technology Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom CSS Variables for Theming
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel
- **Analytics:** Vercel Web Analytics
